# Getting Started

**Funput** is a modern, open-source Vietnamese keyboard for **iPhone**, **iPad**, **macOS**, **Windows**, and **Linux**.

It aims to deliver a consistent typing experience across platforms, with support for **Telex** and **VNI**.
