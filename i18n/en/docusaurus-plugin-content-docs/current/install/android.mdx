# Install Funput on Android

Funput is a Vietnamese keyboard for Android phones and tablets. It supports both **VNI** and **Telex** input methods. After installing the app, you must enable Funput in Android's keyboard settings before you can type in Notes, Messages, or another app.

## Download

Get Funput for free on Google Play:

- [Funput on Google Play](https://play.google.com/store/apps/details?id=app.funput.funput)

## Requirements

- A phone or tablet running Android 8.0 (Oreo, API 26) or later.
- The Funput app installed from [Google Play](https://play.google.com/store/apps/details?id=app.funput.funput).

## Step 1: Open Funput

Open **Funput** from the home screen. On the **Settings** tab, the **Set up Funput** card shows the two required setup steps.

## Step 2: Enable Funput

Tap **Enable Funput** in the app, or open Android's on-screen keyboard settings and turn Funput on.

Some labels may differ slightly depending on the device maker and Android version. A common path is:

**Settings → System → Languages & input → On-screen keyboard → Funput**

## Step 3: Select Funput while typing

1. Open any app with a text field.
2. Tap the text field to display the keyboard.
3. Tap the keyboard icon in the navigation bar, or touch and hold the 🌐 / space bar depending on the device.
4. Select **Funput** from the list.
5. Type a Vietnamese test sentence.

Return to the Funput app. After Funput is selected as the current keyboard, the setup card changes to **Funput is ready**.

## Select VNI or Telex

Open **Funput → Settings → Keyboard → Input method**, then select **VNI** or **Telex**. See [Vietnamese Typing Guide](../input-methods/vietnamese) for key mappings and test examples.

VNI always needs the number row for diacritics, so Funput turns it on automatically when you select VNI. For Telex, the number row is optional — toggle it in **Settings → Keyboard → Number row**.

## If Funput does not appear

- Confirm that Funput is enabled in Android's keyboard settings.
- Close and reopen the app in which you are entering text.
- Tap the keyboard icon in the navigation bar, or touch and hold the 🌐 / space bar, then select Funput.
- Open the Funput keyboard in a text field at least once, then return to the Funput app to refresh its status.

:::note
Android may use the system keyboard in password fields and certain secure text fields. This is an Android security behavior, not a Funput error.
:::
