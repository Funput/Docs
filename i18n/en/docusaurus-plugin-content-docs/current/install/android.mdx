# Funput on Android

Funput brings **Telex** and **VNI** Vietnamese typing to Android — lightweight, open source, and privacy-respecting. Type the same way you do on iOS or desktop, with a consistent experience across platforms.

Android is currently in **closed testing** as required by Google Play. We are expanding the tester group — email us to request an invite.
