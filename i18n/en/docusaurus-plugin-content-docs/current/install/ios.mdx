# Install Funput on iOS

Funput is a Vietnamese keyboard for iPhone and iPad. It supports both **VNI** and **Telex** input methods. After installing the app, you must add Funput to the iOS keyboard list before using it in Notes, Messages, Mail, or another app.

## Download

Get Funput for free on the App Store:

- [Funput on the App Store](https://apps.apple.com/vn/app/id6788829996)

## Requirements

- An iPhone or iPad running iOS/iPadOS 18.6 or later.
- The Funput app installed from the [App Store](https://apps.apple.com/vn/app/id6788829996).

## Step 1: Open Funput

Open **Funput** from the Home Screen. On the **Settings** tab, the **Finish setting up Funput** card shows the three required setup steps.

## Step 2: Add the Funput keyboard

Tap **Open Settings** in Funput, then open **Keyboards**. You can also navigate manually to:

**Settings → General → Keyboard → Keyboards → Add New Keyboard… → Funput**

Some labels may differ slightly depending on the iOS version and system language.

## Step 3: Enable Allow Full Access

Select **Funput** in the keyboard list, turn on **Allow Full Access**, and confirm the iOS prompt.

This permission allows the Funput app to share keyboard preferences such as the input method, theme, personal suggestions, haptics, and sounds with its keyboard extension. Preferences and personal suggestions remain on the device. Funput does not transmit what the user types.

## Step 4: Switch to Funput and type

1. Open **Notes**, **Messages**, or any app with a text field.
2. Tap the text field to display the keyboard.
3. Touch and hold the globe key.
4. Select **Funput** from the keyboard list.
5. Type a Vietnamese test sentence.

## Select VNI or Telex

Open **Funput → Settings → Keyboard → Input method**, then select **VNI** or **Telex**. See [Vietnamese Typing Guide](../input-methods/vietnamese) for key mappings and test examples.

## If Funput does not appear

- Confirm that Funput appears under **Settings → General → Keyboard → Keyboards**.
- Close and reopen the app in which you are entering text.
- Touch and hold the globe key, then select Funput instead of only tapping the key.
- Check that **Allow Full Access** is enabled.
- Open the Funput keyboard in a text field at least once, then return to the Funput app to refresh its status.

:::note
iOS may automatically switch to the system keyboard in password fields and certain secure text fields. This is an iOS security behavior, not a Funput error.
:::
