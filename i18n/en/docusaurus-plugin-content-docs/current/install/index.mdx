# Installation overview

Funput supports **iPhone**, **iPad**, **Android**, **macOS**, **Windows**, and **Linux**. Choose the guide for your operating system:

| Platform | Guide | Status |
| -------- | ----- | ------ |
| iPhone and iPad | [Install on iOS](./ios) | Available |
| Android | [Install on Android](./android) | Available |
| macOS | [Install on macOS](./macos) | Available |
| Windows | [Install on Windows](./windows) | Available |
| Linux | [Install on Linux](./linux) | Available |

## Download

- **iPhone and iPad:** [Funput on the App Store](https://apps.apple.com/vn/app/id6788829996)
- **Android:** [Funput on Google Play](https://play.google.com/store/apps/details?id=app.funput.funput)
- **macOS, Windows, and Linux:** [GitHub Releases](https://github.com/Funput/Funput/releases)

Each GitHub release includes a **SHA-256** checksum file (`.sha256`) so you can verify your download.
