# Install the Funput Vietnamese input method with IBus

<div className={styles.guideBody}>

<span id="when-to-choose-ibus" />

Use this guide if your desktop already uses IBus. Three steps, about 5 minutes, no sign-out needed. On GNOME, you add Funput under **Input Sources** in Settings.

<GuideSteps>

<GuideStep n={1} id="install" title="Install the Funput package for IBus" meta="About 2 minutes. Run commands in Terminal.">

Open **Terminal** from your application menu and select your Linux distribution below. If you already added `repo.funput.app`, start at **Install the package**. If this is your first time using the Funput repository, run both command blocks in order.

<DistroPicker compact>
<DistroFamily id="debian">

**Add the repository once.**

<LinuxRepositoryCommands family="debian" />

**Install the package.**

```bash
sudo apt install funput-ibus
```

</DistroFamily>
<DistroFamily id="fedora">

**Add the repository once.**

<LinuxRepositoryCommands family="fedora" />

**Install the package with DNF.** On Fedora Silverblue or Kinoite, open the section right below.

```bash
sudo dnf install funput-ibus
```

<LinuxGuideDisclosure label="Install on Fedora Silverblue or Kinoite">

After adding the repository, run this command and reboot.

```bash
sudo rpm-ostree install funput-ibus
```

</LinuxGuideDisclosure>

</DistroFamily>
<DistroFamily id="suse">

**Add the repository once.**

<LinuxRepositoryCommands family="suse" />

**Install the package.**

```bash
sudo zypper install funput-ibus
```

</DistroFamily>
<DistroFamily id="arch">

Using Arch Linux ARM? [Install for your account](./other-methods.mdx#user-install).

**Add the repository once.** If `/etc/pacman.conf` already has a `[funput]` section, skip to the install command.

<LinuxRepositoryCommands family="arch" />

**Install the package and update the system in one go.**

```bash
sudo pacman -Syu funput-ibus
```

</DistroFamily>
</DistroPicker>

<LinuxGuideDisclosure label="Terminal asks for a password, or you lack install rights?">

- If `sudo` asks for a password, type your account password and press **Enter**. Terminal shows nothing while you type, which is normal.
- If your account has no administrator rights, [install Funput for your account instead](./other-methods.mdx#user-install).

</LinuxGuideDisclosure>

</GuideStep>

<GuideStep n={2} id="enable" title="Add Funput as an input source" meta="About 1 minute.">

Run this command so IBus loads Funput. Signing out and back in works too.

```bash
ibus restart
```

Open **Settings → Keyboard** and add Funput as shown.

<GnomeInputSourceIllustration />

Switch to **Funput** from the language icon in the top bar, or press <kbd>Super</kbd> + <kbd>Space</kbd>. The **Super** key usually has the Windows logo. With Funput selected, press <kbd>Ctrl</kbd> + <kbd>{'`'}</kbd> to turn Vietnamese typing on or off. You can change this shortcut in **Funput → Phím tắt** (Shortcuts).

</GuideStep>

<GuideStep n={3} id="try-typing" title="Try typing Vietnamese">

Open the **Funput** app to choose **Telex** or **VNI**. Then open a text editor and type along with the animation below.

<TypingDemo />

</GuideStep>

</GuideSteps>

<LinuxGuideDisclosure id="update" label="Update Funput on IBus">

If you added the Funput repository, new releases arrive with your system updates. If you use Terminal, run only the line for your distribution.

```bash
sudo apt update && sudo apt upgrade funput-ibus   # Debian / Ubuntu
sudo dnf upgrade funput-ibus                      # Fedora
sudo zypper update funput-ibus                    # openSUSE
sudo pacman -Syu                                  # Arch (updates the whole system)
```

If Funput misbehaves after an update, run `ibus restart` or sign out and back in.

</LinuxGuideDisclosure>

<LinuxGuideDisclosure id="troubleshooting" label="If Funput is missing or Vietnamese typing doesn't work">

- **Funput is missing from Input Sources.** Check that you installed the `funput-ibus` package, then reload IBus and reopen Settings.
- **Funput is there but letters have no accents.** Select **Funput** again from the input source menu, then check the typing method and whether Vietnamese typing is on in the **Funput** app.
- **Two input methods handle the same keys.** Check whether Fcitx5 is set to start alongside IBus. [Fix two input methods receiving keys](./troubleshooting.mdx#two-frameworks)

</LinuxGuideDisclosure>

<LinuxGuideDisclosure id="switch-to-fcitx5" label="Switch from IBus to Fcitx5">

Follow the Fcitx5 guide from the step that installs the `funput` package. If the Funput repository is already on your machine, you can reuse it. After setting up and signing back in, use Fcitx5 as the input method framework for your session. [Install and enable Funput with Fcitx5](./fcitx5.mdx)

</LinuxGuideDisclosure>
