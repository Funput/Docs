# Other ways to install Funput on Linux

<div className={styles.guideBody}>

On most computers, install from the Funput repository to receive new releases through system updates. If that route does not fit your setup, open one of the options below. [Install from the Funput repository](./index.mdx)

<LinuxGuideDisclosure id="install-sh" label="Install with one command or choose a version">

This option requires administrator access. The installer detects your Linux distribution and architecture, adds the signed Funput repository, and installs the input method. Future releases arrive through system updates.

On **Arch Linux**, follow the repository guide to install Funput and update the system in one operation. [Install Fcitx5 on Arch](./fcitx5.mdx#step-2-add-repo) or [install IBus on Arch](./ibus.mdx#install).

Open **Terminal** and copy the command for the input method you use.

**Fcitx5**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash
```

**IBus**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash -s -- --ibus
```

**Preview the install commands before running them**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash -s -- --dry-run
```

<LinuxGuideDisclosure label="Choose a release or skip the repository">

The one-line installer always adds the Funput repository and installs the newest release. If you need a specific version or don't want to add the repository, [download the DEB or RPM packages from GitHub](#releases) instead. That method installs the input method package together with its `funput-settings` package, and both must come from the same release.

On Arch, use the Funput repository or [install for your own account](#user-install).

</LinuxGuideDisclosure>

After installing, enable the input method you chose.

- [Set up Fcitx5](./fcitx5.mdx#step-3-wire-session)
- [Add Funput to IBus](./ibus.mdx#enable)

</div>

</LinuxGuideDisclosure>

<LinuxGuideDisclosure id="user-install" label="Install for your own account without sudo">

Use this option if you lack administrator access, use Arch Linux ARM, or your distribution has no matching Funput package. It installs Funput into your home folder (`~/.local`) without using the system package manager.

Your computer needs **x86-64** or **ARM64**, compatible system libraries, and an existing **Fcitx5** or **IBus** installation. Ask your administrator to install the input method first if it is missing.

**Fcitx5**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash -s -- --user
```

The installer sets `FCITX_ADDON_DIRS` in `~/.config/environment.d/funput.conf` so that Fcitx5 can find Funput. If Fcitx5 still doesn't see Funput after you sign back in, your system may not read that folder. In that case, [copy the `FCITX_ADDON_DIRS` line from the file to a place your system does read](./session-setup.mdx#where-to-set). If you have not set up Fcitx5, [configure it for your desktop](./fcitx5.mdx#step-3-wire-session). Sign out and back in, then [add Funput and try typing](./fcitx5.mdx#step-4-enable).

**IBus**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash -s -- --user --ibus
```

IBus finds the input method in `~/.local/share/ibus/component`. If Funput does not appear in **Input Sources**, run `ibus restart`, then [add Funput and try typing](./ibus.mdx#enable).

To update, run the same install command again and reload your input method as shown above.

</LinuxGuideDisclosure>

<LinuxGuideDisclosure id="releases" label="Download DEB or RPM packages from GitHub">

Use this option if you want to choose and install the files yourself. Choose **DEB** for Debian or Ubuntu and **RPM** for Fedora or openSUSE. Arch Linux uses the repository for system packages. To check your machine's architecture, run `uname -m` in Terminal.

| Output of `uname -m` | Look for in DEB names | Look for in RPM names |
| --- | --- | --- |
| `x86_64` | `amd64` | `x86_64` |
| `aarch64` | `arm64` | `aarch64` |

<div className={styles.enableFlow}>

1. **Open Assets.** Pick a release and expand its list of files. [Download Funput from GitHub](https://github.com/Funput/Funput/releases)
2. **Download two files.** Get `funput` for Fcitx5 or `funput-ibus` for IBus, plus `funput-settings`. Choose both from the same release and for the same architecture.
3. **Open the download folder.** Put the two files alone in a new folder. In your file manager, open that folder and choose **Open in Terminal** if available.

</div>

For example, if the folder is named `funput-install` in `Downloads`, open Terminal and run `cd ~/Downloads/funput-install`. The `*` in each command selects every file with that extension, so check that the folder contains only the two files you downloaded.

**Debian or Ubuntu**

```bash
sudo apt install ./*.deb
```

**Fedora**

```bash
sudo dnf install ./*.rpm
```

**openSUSE**

```bash
sudo zypper install --allow-unsigned-rpm ./*.rpm
```

Packages downloaded from GitHub do not carry the repository's GPG signature. The `--allow-unsigned-rpm` option lets openSUSE install the two files downloaded from the official releases page. Download the DEB file again if `apt` or `dpkg` reports `could not locate member control.tar` or `unexpected end of file`.

For a first install, enable the input method before trying it.

<div className={styles.quickLinks}>

- [Set up and enable Funput with Fcitx5](./fcitx5.mdx#step-3-wire-session)
- [Add Funput to IBus and try typing](./ibus.mdx#enable)

</div>

To update, download the new pair of packages and install them as above. Sign out and back in for Fcitx5, or run `ibus restart` for IBus.

</LinuxGuideDisclosure>

<LinuxGuideDisclosure id="unsupported-distros" label="Install on a Linux distribution outside the list">

Search for the name of your Linux distribution. The installer matches `ID` and then `ID_LIKE` in `/etc/os-release` to find distributions that use APT, DNF, Zypper or Pacman. [Open the distribution picker](./fcitx5.mdx#step-2-add-repo)

If your distribution is outside those groups, such as Alpine, Void, Gentoo, NixOS or Solus, try [installing for your own account](#user-install) if the machine has Fcitx5 or IBus and compatible system libraries. If you already build software from source, use `platforms/linux/build.sh`. [Funput source on GitHub](https://github.com/Funput/Funput)

</LinuxGuideDisclosure>

### Why are there no Flatpak, Snap or AppImage packages?

Fcitx5 or IBus loads Funput as an input method. The installation methods above put the files where the input system can find them.
