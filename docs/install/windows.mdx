# Cài đặt trên Windows

Funput đã có trên **[Microsoft Store](https://apps.microsoft.com/store/detail/9NR3WL5PD4ZS)**. Cài miễn phí, mở từ menu Start và cập nhật qua Store. Ứng dụng chạy nền ở **khay hệ thống (System Tray)** để bạn gõ tiếng Việt, không cần thêm Input Source như macOS hay Linux.

Nếu cần mang ứng dụng theo trong một thư mục, bản **portable một file `.exe`** vẫn có trên GitHub Releases.

## Yêu cầu \{#requirements\}

| | |
| --- | --- |
| **Hệ điều hành** | Windows 10 phiên bản **1809** (build 17763) trở lên · Windows 11 |
| **Kiến trúc** | **x86-64**. Windows on ARM chạy được qua emulation, nhưng chưa có bản build riêng |
| **Runtime ngoài** | Không cần — không WebView2, không .NET |

:::note[Vì sao là build 17763?]
Đó là mốc Windows bắt đầu hỗ trợ nền **Acrylic** mà Control Center của Funput dùng. Bản Windows cũ hơn không bị chặn chạy, nhưng chưa được thử nghiệm và Control Center sẽ mất hiệu ứng nền.

Riêng nền **Mica** chỉ có trên Windows 11. Trên Windows 10, cửa sổ Cài đặt hiển thị nền đục — đây là lựa chọn cố ý để cửa sổ không bị giật khi kéo/thay đổi kích thước, không phải lỗi.
:::

## Tải xuống \{#download\}

### Microsoft Store (khuyến nghị)

Mở **[Funput trên Microsoft Store](https://apps.microsoft.com/store/detail/9NR3WL5PD4ZS)** và chọn **Nhận / Get** hoặc **Cài đặt / Install**. Nếu trình duyệt đề nghị mở ứng dụng Microsoft Store, tiếp tục trong Store để hoàn tất cài đặt.

### Bản portable

Tải bản portable từ [GitHub Releases](https://github.com/Funput/Funput/releases):

| File | Mô tả |
| ---- | ----- |
| `Funput-<version>.exe` | App portable, một file duy nhất |
| `Funput-<version>.exe.sha256` | Checksum SHA-256 để kiểm tra tính toàn vẹn |

**Kiểm tra SHA-256** (PowerShell):

```powershell
Get-FileHash .\Funput-*.exe -Algorithm SHA256
```

So sánh kết quả với nội dung file `.sha256` trên trang release.

## Cài đặt / chạy lần đầu \{#install\}

### Cài từ Microsoft Store

1. Mở [trang Funput trên Microsoft Store](https://apps.microsoft.com/store/detail/9NR3WL5PD4ZS) và cài ứng dụng.
2. Chọn **Mở / Open** trong Store hoặc tìm **Funput** trong menu Start.
3. Làm theo hướng dẫn chọn kiểu gõ. Biểu tượng Funput xuất hiện ở khay hệ thống.
4. Chọn Telex, Telex+ hoặc VNI và thử gõ trong Notepad.

Nếu đang dùng bản portable hoặc bộ gõ khác, thoát bộ gõ đang chạy trước khi mở bản mới. Khi chuyển bản cài, có thể giữ thiết lập bằng **Cài đặt → Dữ liệu → Xuất cấu hình**, rồi nhập lại trong bản mới.

### Chạy bản portable

Các bước về thư mục, đổi tên tệp và SmartScreen dưới đây chỉ dành cho bản portable.

1. Tải file `Funput-*.exe` từ GitHub Releases.
2. Đặt file vào một thư mục cố định, ví dụ `%LOCALAPPDATA%\Programs\Funput\`.
3. Double-click để chạy — icon **f** của Funput xuất hiện ở khay hệ thống (góc dưới phải màn hình).
4. Cửa sổ **Onboarding** mở ra hướng dẫn chọn kiểu gõ; xong là gõ tiếng Việt được ngay.

:::tip[Đặt file ở đâu]
Đừng để app trong thư mục **Downloads** — bạn dễ xoá nhầm khi dọn máy, và cấu hình nằm cùng chỗ với app nên sẽ mất theo. `%LOCALAPPDATA%\Programs\Funput\` là lựa chọn tốt: không cần quyền admin và Funput ghi cấu hình vào đó được.
:::

:::danger[File bạn vừa tải sẽ tự đổi tên — đừng hoảng]

Ở lần chạy đầu tiên, `Funput-<version>.exe` **tự nhân bản thành `Funput.exe`** nằm cùng thư mục, khởi động lại từ file mới, rồi **xoá file có số phiên bản** đi.

Đây là hành vi cố ý: tính năng khởi động cùng Windows và tự cập nhật cần một đường dẫn cố định, không đổi theo phiên bản. Từ lần sau, bạn chỉ chạy `Funput.exe`.

:::

:::warning[SmartScreen]

Bản portable tải từ GitHub có thể hiện cảnh báo **SmartScreen** lần đầu. Nếu bạn tải từ [GitHub Releases](https://github.com/Funput/Funput/releases) chính thức:

1. Chọn **More info** (Thông tin thêm)
2. Chọn **Run anyway** (Vẫn chạy)

:::

## Bắt đầu gõ \{#start-typing\}

Phím tắt bật/tắt tiếng Việt mặc định là **`Ctrl` + `` ` ``** (đổi được trong Cài đặt sang `Ctrl Space` hoặc `Alt Shift`).

Thử gõ nhanh:

| Kiểu gõ | Gõ thế này | Ra thế này |
| --- | --- | --- |
| **Telex** | `tieesng vieejt` | tiếng việt |
| **VNI** | `xin chao2` | xin chào |

:::info[Telex và VNI khác nhau chỗ nào?]
**Telex** đặt dấu bằng chữ cái: `s` sắc, `f` huyền, `r` hỏi, `x` ngã, `j` nặng — nên `chaof` ra `chào`.

**VNI** đặt dấu bằng chữ số: `1` sắc, `2` huyền, `3` hỏi, `4` ngã, `5` nặng — nên `chao2` mới ra `chào`.

Funput còn có **Telex+**: giữ nguyên Telex và thêm `w` đầu từ cùng phím tắt `[` `]` cho `ư` `ơ`.
:::

## Dùng System Tray \{#system-tray\}

Icon Funput trên khay hệ thống là trung tâm điều khiển:

| Thao tác | Chức năng |
| -------- | --------- |
| **Click trái** | Mở / đóng **Control Center** |
| **Click phải** | Mở menu ngữ cảnh |

**Control Center** (click trái) là bảng điều khiển nhanh, bật/tắt ngay mà không phải mở Cài đặt:

- Bật / tắt **gõ tiếng Việt**
- Đổi **kiểu gõ** — Telex · Telex+ · VNI
- Bật nhanh **Kiểm tra chính tả**, **Khôi phục tiếng Anh**, **Tự động viết hoa**
- Xem **phím chuyển** và **kiểu đặt dấu** đang dùng
- **Mở cài đặt đầy đủ**

**Menu click phải** của bản portable gồm bốn mục; bản Microsoft Store không có mục Kiểm tra cập nhật:

- **Cài đặt…**
- **Chuyển mã…**
- **Kiểm tra cập nhật…**
- **Thoát**

:::tip
Icon tray đổi **màu ↔ trắng đen** theo trạng thái: có màu là đang gõ tiếng Việt, trắng đen là đang gõ tiếng Anh. Liếc một cái là biết, không cần mở gì.
:::

## Cấu hình \{#configuration\}

Mở **Cài đặt…** từ menu tray. Cửa sổ chia làm sáu mục:

| Mục | Chỉnh được gì |
| --- | --- |
| **Tổng quan** | Bật/tắt tiếng Việt · kiểu gõ · tự tắt khi đổi bàn phím (Nhật, Hàn, Trung…) · khởi động cùng Windows |
| **Cách gõ** | Kiểu gõ · kiểu đặt dấu (truyền thống `hòa` / hiện đại `hoà`) · tự khôi phục tiếng Anh · khôi phục tức thì · kiểm tra chính tả · tự động viết hoa |
| **Phím tắt** | Phím chuyển VI/EN · phím lật lại từ vừa gõ (mặc định tắt) |
| **Gõ tắt** | Bảng viết tắt tự bung, tuỳ chọn khớp cả hoa lẫn thường |
| **Dữ liệu** | Xuất / nhập cấu hình · công cụ Chuyển mã · nhập bảng gõ tắt từ UniKey |
| **Giới thiệu** | Phiên bản · kiểm tra cập nhật · liên kết |

Thay đổi có hiệu lực ngay và được giữ qua các lần khởi động lại.

### Cấu hình lưu ở đâu \{#config-location\}

Với bản **portable**, cấu hình nằm ngay cạnh file `Funput.exe` để cả app đi theo USB được. Nó chọn vị trí theo thứ tự sau:

| Thứ tự | Vị trí | Khi nào dùng |
| --- | --- | --- |
| 1 | `%FUNPUT_CONFIG%` | Chỉ khi bạn tự đặt biến môi trường này |
| 2 | `<thư mục chứa Funput.exe>\settings.json` | **Trường hợp thường gặp** — khi thư mục đó ghi được |
| 3 | `%APPDATA%\Funput\settings.json` | Dự phòng, khi thư mục chứa app chỉ đọc |

:::info
Đặt app trong `C:\Program Files\Funput\` sẽ rơi vào trường hợp 3, vì thư mục đó cần quyền admin để ghi. Đặt trong `%LOCALAPPDATA%\Programs\Funput\` thì cấu hình nằm cùng chỗ với app.
:::

Với bản **Microsoft Store**, Windows quản lý thư mục cài đặt. Không di chuyển hoặc sửa tệp trong `WindowsApps`; dùng **Cài đặt → Dữ liệu** để xuất / nhập cấu hình.

## Giới hạn đã biết \{#known-limitations\}

:::danger[Không gõ được vào ứng dụng chạy quyền Administrator]

Task Manager, Registry Editor, một số trình cài đặt và công cụ quản trị chạy ở quyền cao hơn Funput, nên Windows **chặn** Funput đưa phím vào các cửa sổ đó. Đây là cơ chế bảo vệ của hệ điều hành, không phải lỗi của app.

**Với bản portable:** click phải `Funput.exe` → **Run as administrator**. Funput sẽ gõ được vào cả ứng dụng thường lẫn ứng dụng elevated.

:::

- **Bản portable không tự kiểm tra cập nhật nền.** Bạn phải chủ động chọn **Kiểm tra cập nhật…**.
- **Bản Store cập nhật qua Microsoft Store.** Không thay tệp ứng dụng thủ công.
- **Bản portable có thể hiện SmartScreen** ở lần chạy đầu tiên; chỉ tải từ GitHub Releases chính thức.

## Cập nhật \{#update\}

### Bản Microsoft Store

Mở Microsoft Store và kiểm tra bản cập nhật Funput trong phần quản lý ứng dụng / Thư viện. Store quản lý cập nhật của bản cài này; trong **Cài đặt → Giới thiệu**, Funput hiển thị **Cập nhật qua Microsoft Store** và không có thao tác tải bản GitHub.

Các cách cập nhật dưới đây dành cho **bản portable**.

### Cập nhật bản portable trong app \{#update-in-app\}

| Cách truy cập | Thao tác |
| ------------- | -------- |
| **System Tray** | Click phải icon Funput → **Kiểm tra cập nhật…** |
| **Cài đặt** | **Cài đặt → Giới thiệu → Kiểm tra cập nhật…** |

Quy trình khi có bản mới:

1. App đọc manifest `funput-windows.json` từ GitHub Releases
2. Tải file `.exe` mới
3. **Xác minh chữ ký Ed25519** (cùng public key với bản macOS)
4. Thay thế exe đang chạy và khởi động lại — **không cần đăng xuất**

:::info
Funput **không tự kiểm tra cập nhật nền** — bạn cần chủ động chọn **Kiểm tra cập nhật…**.
:::

### Cập nhật bản portable thủ công \{#update-manual\}

1. Tải `Funput-<version>.exe` mới từ [GitHub Releases](https://github.com/Funput/Funput/releases)
2. Thoát Funput (menu tray → **Thoát**)
3. Đặt file mới vào **cùng thư mục** với `Funput.exe` cũ, rồi double-click file mới
4. Funput tự thay `Funput.exe` bằng bản mới và dọn file có số phiên bản

## Gỡ cài đặt \{#uninstall\}

### Bản Microsoft Store

Thoát Funput từ khay hệ thống. Mở **Settings → Apps**, tìm **Funput** trong danh sách ứng dụng đã cài và chọn **Uninstall / Gỡ cài đặt**. Xuất cấu hình từ **Cài đặt → Dữ liệu** trước khi gỡ nếu muốn giữ thiết lập.

### Bản portable

Bản portable không có trình gỡ cài đặt. Cần dọn ba thứ:

1. **Thoát Funput** từ menu tray, rồi xoá thư mục chứa app.
2. **Xoá mục khởi động cùng Windows**, nếu bạn đã bật.
3. **Xoá cấu hình dự phòng** trong `%APPDATA%`, nếu có.

Chạy trong PowerShell (sửa đường dẫn ở dòng đầu cho khớp nơi bạn đặt app):

```powershell
Remove-Item -Recurse "$env:LOCALAPPDATA\Programs\Funput"
Remove-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Run" -Name Funput -ErrorAction SilentlyContinue
Remove-Item -Recurse "$env:APPDATA\Funput" -ErrorAction SilentlyContinue
```

:::caution
Xoá thư mục app cũng xoá `settings.json` nằm trong đó. Muốn giữ lại cấu hình, vào **Cài đặt → Dữ liệu → Xuất cấu hình** trước khi gỡ.
:::

## Xử lý sự cố \{#troubleshooting\}

### SmartScreen chặn hoặc cảnh báo \{#smartscreen\}

Với bản portable, xem mục [Cài đặt / chạy lần đầu](#install). Chỉ tải từ [GitHub Releases](https://github.com/Funput/Funput/releases) chính thức.

### Không gõ được trong app chạy quyền Admin \{#admin-apps\}

Xem mục [Giới hạn đã biết](#known-limitations). Với bản portable, chạy Funput bằng **Run as administrator**.

### File `Funput-<version>.exe` biến mất sau khi chạy \{#exe-disappears\}

Bình thường. Funput đã đổi nó thành `Funput.exe` cùng thư mục — xem mục [Cài đặt / chạy lần đầu](#install).

### Gõ VNI mà không ra dấu \{#vni-no-tones\}

VNI đặt dấu bằng **chữ số** (`chao2` → `chào`), không phải chữ cái. Nếu bạn quen `chaof` thì đang gõ **Telex** — đổi kiểu gõ trong Control Center hoặc **Cài đặt → Cách gõ**.

### Funput không tự khởi động khi bật máy \{#no-autostart\}

Bật **Khởi động cùng Windows** trong **Cài đặt → Tổng quan**. Với bản Store, kiểm tra thêm **Settings → Apps → Startup** nếu Windows đã tắt quyền khởi động. Với bản portable, nếu bạn di chuyển `Funput.exe` sang thư mục khác, hãy tắt rồi bật lại tuỳ chọn này để Funput ghi lại đường dẫn mới.

### Không thấy icon Funput trên khay hệ thống \{#no-tray-icon\}

- Kiểm tra vùng **hidden icons** (mũi tên ^ trên taskbar) — Windows thường ẩn icon mới.
- Mở Funput từ menu Start (bản Store) hoặc chạy lại `Funput.exe` (bản portable). Nếu Funput đã chạy sẵn, lần chạy thứ hai chỉ mở cửa sổ Cài đặt — đó là dấu hiệu app vẫn sống và icon chỉ đang bị ẩn.
- Khởi động lại Windows nếu app bị crash im lặng.

### Cài đặt không được lưu \{#settings-not-saved\}

Thư mục chứa app có thể chỉ đọc. Kiểm tra xem `settings.json` nằm ở đâu theo bảng trong mục [Cấu hình lưu ở đâu](#config-location), hoặc chuyển app sang `%LOCALAPPDATA%\Programs\Funput\`.

### File `.exe` nghi bị hỏng \{#corrupt-exe\}

Đối chiếu SHA-256 (xem mục [Tải xuống](#download)) và tải lại nếu không khớp.
