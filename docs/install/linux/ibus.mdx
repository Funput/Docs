# Cài bộ gõ tiếng Việt Funput với IBus

<div className={styles.guideBody}>

<span id="when-to-choose-ibus" />

Dùng hướng dẫn này nếu máy đang dùng IBus. Ba bước, khoảng 5 phút, không cần đăng xuất. Trên GNOME, bạn sẽ thêm Funput trong mục **Nguồn nhập** của Cài đặt.

<GuideSteps>

<GuideStep n={1} id="install" title="Cài gói Funput cho IBus" meta="Khoảng 2 phút. Chạy lệnh trong Terminal.">

Mở **Terminal** từ menu ứng dụng rồi chọn bản phân phối bên dưới. Nếu máy đã thêm kho `repo.funput.app`, bắt đầu ở **Cài gói**. Nếu đây là lần đầu dùng kho Funput, chạy cả hai khối lệnh theo thứ tự.

<DistroPicker compact>
<DistroFamily id="debian">

**Thêm kho lần đầu.**

<LinuxRepositoryCommands family="debian" />

**Cài gói.**

```bash
sudo apt install funput-ibus
```

</DistroFamily>
<DistroFamily id="fedora">

**Thêm kho lần đầu.**

<LinuxRepositoryCommands family="fedora" />

**Cài gói bằng DNF.** Nếu dùng Fedora Silverblue hoặc Kinoite, mở phần hướng dẫn ngay bên dưới.

```bash
sudo dnf install funput-ibus
```

<LinuxGuideDisclosure label="Cài gói trên Fedora Silverblue hoặc Kinoite">

Sau khi thêm kho, chạy lệnh này rồi khởi động lại máy.

```bash
sudo rpm-ostree install funput-ibus
```

</LinuxGuideDisclosure>

</DistroFamily>
<DistroFamily id="suse">

**Thêm kho lần đầu.**

<LinuxRepositoryCommands family="suse" />

**Cài gói.**

```bash
sudo zypper install funput-ibus
```

</DistroFamily>
<DistroFamily id="arch">

Dùng Arch Linux ARM? [Cài cho tài khoản của bạn](./other-methods.mdx#user-install).

**Thêm kho lần đầu.** Nếu `/etc/pacman.conf` đã có mục `[funput]`, chuyển thẳng đến lệnh cài.

<LinuxRepositoryCommands family="arch" />

**Cài gói và cập nhật hệ thống cùng lúc.**

```bash
sudo pacman -Syu funput-ibus
```

</DistroFamily>
</DistroPicker>

<LinuxGuideDisclosure label="Terminal hỏi mật khẩu hoặc bạn thiếu quyền cài đặt?">

- Nếu `sudo` hỏi mật khẩu, nhập mật khẩu tài khoản rồi nhấn **Enter**. Terminal không hiện ký tự khi bạn gõ, đó là bình thường.
- Nếu tài khoản thiếu quyền quản trị, [xem cách cài cho tài khoản của bạn](./other-methods.mdx#user-install).

</LinuxGuideDisclosure>

</GuideStep>

<GuideStep n={2} id="enable" title="Thêm Funput vào nguồn nhập" meta="Khoảng 1 phút.">

Chạy lệnh sau để IBus nạp Funput. Bạn cũng có thể đăng xuất rồi đăng nhập lại.

```bash
ibus restart
```

Mở **Settings (Cài đặt) → Keyboard (Bàn phím)** rồi thêm Funput như hình.

<GnomeInputSourceIllustration />

Chuyển sang **Funput** từ biểu tượng ngôn ngữ trên thanh hệ thống hoặc nhấn <kbd>Super</kbd> + <kbd>Space</kbd>. Phím **Super** thường có biểu tượng Windows. Khi đang dùng Funput, nhấn <kbd>Ctrl</kbd> + <kbd>{'`'}</kbd> để bật hoặc tắt chế độ gõ tiếng Việt, phím này đổi được trong **Funput → Phím tắt**.

</GuideStep>

<GuideStep n={3} id="try-typing" title="Gõ thử tiếng Việt">

Mở ứng dụng **Funput** để chọn **Telex** hoặc **VNI**. Sau đó mở một trình soạn thảo văn bản và gõ giống hoạt cảnh dưới đây.

<TypingDemo />

</GuideStep>

</GuideSteps>

<LinuxGuideDisclosure id="update" label="Cập nhật Funput trên IBus">

Nếu đã thêm kho Funput, bạn có thể nhận bản mới khi cập nhật phần mềm trên máy. Nếu dùng Terminal, chỉ chạy lệnh dành cho bản phân phối của bạn.

```bash
sudo apt update && sudo apt upgrade funput-ibus   # Debian / Ubuntu
sudo dnf upgrade funput-ibus                      # Fedora
sudo zypper update funput-ibus                    # openSUSE
sudo pacman -Syu                                  # Arch (cập nhật cả hệ thống)
```

Nếu Funput hoạt động chưa ổn sau khi cập nhật, chạy `ibus restart` hoặc đăng xuất rồi đăng nhập lại.

</LinuxGuideDisclosure>

<LinuxGuideDisclosure id="troubleshooting" label="Nếu chưa thấy Funput hoặc chưa gõ được tiếng Việt">

- **Không thấy Funput trong Nguồn nhập.** Kiểm tra bạn đã cài đúng gói `funput-ibus`, rồi nạp lại IBus và mở lại Cài đặt.
- **Thấy Funput nhưng chữ vẫn không dấu.** Chọn lại **Funput** từ menu nguồn nhập, sau đó kiểm tra kiểu gõ và trạng thái tiếng Việt trong ứng dụng **Funput**.
- **Hai bộ gõ cùng xử lý phím.** Kiểm tra xem Fcitx5 có được thiết lập tự khởi động cùng IBus hay không. [Xử lý lỗi hai bộ gõ cùng nhận phím](./troubleshooting.mdx#two-frameworks)

</LinuxGuideDisclosure>

<LinuxGuideDisclosure id="switch-to-fcitx5" label="Chuyển từ IBus sang Fcitx5">

Làm theo hướng dẫn Fcitx5 từ bước cài gói `funput`. Nếu máy đã có kho Funput, bạn có thể dùng lại kho đó. Sau khi thiết lập và đăng nhập lại, dùng Fcitx5 làm hệ thống bộ gõ của phiên hiện tại. [Cài và bật Funput với Fcitx5](./fcitx5.mdx)

</LinuxGuideDisclosure>
