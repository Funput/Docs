## Chưa biết chọn bản nào? \{#choose\}

Nhìn màn hình máy bạn rồi tìm ô giống nhất.

<Chooser>
<ChoiceRow look="gnome" title="GNOME trên Ubuntu hoặc Fedora" hint="Thanh mỏng ở cạnh trên màn hình">

Chọn [IBus](./ibus.mdx) nếu muốn ít bước nhất. Chọn [Fcitx5](./fcitx5.mdx) nếu bạn hay gõ trong WPS Office.

</ChoiceRow>
<ChoiceRow look="kde" title="KDE Plasma" hint="Kubuntu, Fedora KDE, openSUSE, KDE neon">

Chọn [Fcitx5](./fcitx5.mdx). KDE Plasma có sẵn chỗ bật Fcitx5 trong System Settings.

</ChoiceRow>
<ChoiceRow look="other" title="Giao diện khác" hint="Linux Mint, Xubuntu, MATE và các bản còn lại">

Chọn [Fcitx5](./fcitx5.mdx), cách khuyến nghị cho hầu hết máy.

</ChoiceRow>
</Chooser>
