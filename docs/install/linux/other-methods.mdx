# Các cách cài Funput khác trên Linux

<div className={styles.guideBody}>

Với đa số máy, hãy cài từ kho Funput để nhận bản mới cùng các bản cập nhật hệ thống. Nếu cách đó chưa phù hợp, mở một mục bên dưới. [Hướng dẫn cài từ kho Funput](./index.mdx)

<LinuxGuideDisclosure id="install-sh" label="Cài nhanh bằng một lệnh hoặc chọn phiên bản">

Cách này cần quyền quản trị. Lệnh cài tự nhận diện bản Linux và kiến trúc máy, thêm kho Funput rồi cài bộ gõ. Các bản cập nhật sau đó đi cùng bản cập nhật hệ thống.

Trên Arch Linux `x86_64`, dùng hướng dẫn cài từ kho để cài Funput và cập nhật hệ thống trong cùng một lần chạy. [Cài Fcitx5 trên Arch](./fcitx5.mdx#step-2-add-repo) hoặc [cài IBus trên Arch](./ibus.mdx#install).

Mở **Terminal** rồi sao chép lệnh cho bộ gõ bạn dùng.

**Fcitx5**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash
```

**IBus**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash -s -- --ibus
```

**Xem trước các lệnh cài mà chưa chạy**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash -s -- --dry-run
```

<LinuxGuideDisclosure label="Cài một phiên bản cụ thể hoặc cài không thêm kho">

Lệnh cài nhanh luôn thêm kho Funput và cài bản mới nhất. Nếu bạn cần một phiên bản cụ thể hoặc không muốn thêm kho, hãy [tự tải gói DEB hoặc RPM từ GitHub](#releases). Cách đó cài cùng lúc gói bộ gõ và gói `funput-settings` đi kèm, hai gói này phải cùng phiên bản.

Với Arch, hãy dùng kho Funput hoặc [cài cho tài khoản của bạn](#user-install).

</LinuxGuideDisclosure>

Sau khi cài, hãy bật bộ gõ bạn vừa chọn.

<LinuxGuideDisclosure id="user-install" label="Cài cho tài khoản của bạn, không cần sudo">

Dùng cách này khi bạn không có quyền quản trị, dùng Arch Linux ARM hoặc máy chưa có gói Funput phù hợp. Funput được cài trong thư mục cá nhân của bạn (`~/.local`).

Máy cần dùng kiến trúc **x86-64** hoặc **ARM64**, có thư viện tương thích và đã cài sẵn **Fcitx5** hoặc **IBus**. Nếu thiếu bộ gõ, nhờ người quản trị máy cài trước.

**Fcitx5**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash -s -- --user
```

Công cụ cài sẽ lưu cấu hình để Fcitx5 tìm thấy Funput. Tệp thường nằm ở `~/.config/environment.d/funput.conf`. Nếu sau khi đăng nhập lại Fcitx5 vẫn không thấy Funput, có thể máy không đọc thư mục này. Khi đó, [chép dòng `FCITX_ADDON_DIRS` trong tệp sang nơi máy đọc thiết lập](./session-setup.mdx#where-to-set). Nếu chưa thiết lập Fcitx5, hãy [cấu hình theo giao diện Linux đang dùng](./fcitx5.mdx#step-3-wire-session). Đăng xuất, đăng nhập lại rồi [thêm Funput và gõ thử](./fcitx5.mdx#step-4-enable).

**IBus**

```bash
curl -fsSL https://raw.githubusercontent.com/Funput/Funput/main/platforms/linux/install.sh | bash -s -- --user --ibus
```

Nếu chưa thấy Funput trong **Nguồn nhập**, chạy `ibus restart` rồi [thêm Funput và gõ thử](./ibus.mdx#enable).

Để cập nhật, chạy lại lệnh vừa chọn rồi nạp lại bộ gõ theo hướng dẫn ở trên.

</LinuxGuideDisclosure>

<LinuxGuideDisclosure id="releases" label="Tự tải gói DEB hoặc RPM từ GitHub">

Dùng cách này khi bạn muốn tự chọn tệp cài. Chọn **DEB** cho Debian hoặc Ubuntu, hoặc **RPM** cho Fedora hoặc openSUSE. Nếu chưa biết máy cần bản nào, hãy chạy `uname -m` trong Terminal rồi đối chiếu với bảng.

| Kết quả của `uname -m` | Tìm trong tên gói DEB | Tìm trong tên gói RPM |
| --- | --- | --- |
| `x86_64` | `amd64` | `x86_64` |
| `aarch64` | `arm64` | `aarch64` |

<div className={styles.enableFlow}>

1. **Mở mục Assets.** Chọn một phiên bản rồi mở danh sách tệp cài. [Tải Funput trên GitHub](https://github.com/Funput/Funput/releases)
2. **Tải hai tệp.** Lấy gói `funput` cho Fcitx5 hoặc `funput-ibus` cho IBus, kèm `funput-settings`. Chọn cả hai từ cùng phiên bản và cùng kiến trúc.
3. **Mở thư mục tải về.** Đặt riêng hai tệp vào một thư mục mới. Mở thư mục đó trong trình quản lý tệp rồi chọn **Open in Terminal (Mở trong Terminal)** nếu có.

</div>

Nếu thư mục của bạn là `funput-install` trong `Downloads`, bạn cũng có thể mở Terminal và chạy `cd ~/Downloads/funput-install`. Dấu `*` chọn toàn bộ tệp có cùng đuôi, nên hãy kiểm tra thư mục chỉ chứa đúng hai gói vừa tải.

**Debian hoặc Ubuntu**

```bash
sudo apt install ./*.deb
```

**Fedora**

```bash
sudo dnf install ./*.rpm
```

**openSUSE**

```bash
sudo zypper install --allow-unsigned-rpm ./*.rpm
```

Gói tải rời trên GitHub không có chữ ký của kho Funput. Tùy chọn `--allow-unsigned-rpm` cho phép openSUSE cài hai tệp tải từ trang phát hành chính thức. Nếu `apt` hoặc `dpkg` báo `unexpected end of file` hay `could not locate member control.tar`, hãy tải lại tệp `.deb` rồi thử lại.

Lần đầu cài, hãy bật bộ gõ trước khi gõ thử.

<div className={styles.quickLinks}>

- [Thiết lập và bật Funput với Fcitx5](./fcitx5.mdx#step-3-wire-session)
- [Thêm Funput vào IBus và gõ thử](./ibus.mdx#enable)

</div>

Khi có bản mới, tải lại cả hai tệp và cài như trên. Với Fcitx5, đăng xuất rồi đăng nhập lại. Với IBus, chạy `ibus restart`.

</LinuxGuideDisclosure>

<LinuxGuideDisclosure id="unsupported-distros" label="Cài trên bản Linux chưa có trong danh sách">

Tìm tên bản Linux bạn đang dùng. Công cụ cài nhận diện các bản thuộc bốn nhóm dùng APT, DNF, Zypper hoặc Pacman. [Mở bộ chọn bản phân phối Linux](./fcitx5.mdx#step-2-add-repo)

Nếu bản của bạn nằm ngoài các nhóm này, hãy thử [cài cho tài khoản của bạn](#user-install) khi máy đã có Fcitx5 hoặc IBus và thư viện tương thích. Nếu quen tự biên dịch phần mềm, bạn có thể dùng `platforms/linux/build.sh`. [Mã nguồn Funput trên GitHub](https://github.com/Funput/Funput)

</LinuxGuideDisclosure>

### Vì sao không có gói Flatpak, Snap hay AppImage?

Funput được cài vào thư mục mà Fcitx5 hoặc IBus đọc để nạp bộ gõ. Các cách cài trên đặt tệp vào đúng thư mục đó.
