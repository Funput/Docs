# Tổng quan cài đặt

Funput hỗ trợ **iPhone**, **iPad**, **Android**, **macOS**, **Windows** và **Linux**. Chọn hướng dẫn phù hợp với hệ điều hành bạn đang dùng:

| Nền tảng | Hướng dẫn | Trạng thái |
| -------- | --------- | ---------- |
| iPhone và iPad | [Cài đặt trên iOS](./ios) | Sẵn sàng |
| Android | [Cài đặt trên Android](./android) | Sẵn sàng |
| macOS | [Cài đặt trên macOS](./macos) | Sẵn sàng |
| Windows | [Cài đặt trên Windows](./windows) | Sẵn sàng |
| Linux | [Cài đặt trên Linux](./linux) | Sẵn sàng |

## Tải xuống \{#downloads\}

- **iPhone và iPad:** [Funput trên App Store](https://apps.apple.com/vn/app/id6788829996)
- **Android:** [Funput trên Google Play](https://play.google.com/store/apps/details?id=app.funput.funput)
- **macOS, Windows và Linux:** [Bản phát hành trên GitHub](https://github.com/Funput/Funput/releases)

Mỗi bản phát hành trên GitHub kèm file checksum **SHA-256** (`.sha256`) để bạn kiểm tra tính toàn vẹn của file tải về.
